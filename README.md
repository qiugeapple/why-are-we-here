# why-are-we-here

本科学习的阶段，亲身经历了ai的快速发展，大一的时候我们还在一个字一个字地敲论文，到了大二时我们已经开始用ai完成信息检索，大三时期已经在用ai辅助我们进行设计的头脑风暴，绘制初期草图。而在这个过程中，我意识到在ai的辅助下我可以很快地将我脑中模糊的想法，变成一个清晰的方案，在毕设阶段，我的同学使用了ai完成整个设计，但其过程仍然相当痛苦，如何决定ai生成的效果，确定自己想要的方向，以及怎么样一步一步迭代下去，项目内容是向老人科普八段锦，见证了她们的产出后，我意识到在这个时代下，设计师的立身之本从执行者变成了决定者，决定设计的内容。而在决定如何设计内容时，工具也会反过来塑造我们的想象力，正如我本科的专业是视觉传达，我们的设计总是停留在纸媒的想象，多以平面为基础，除去纸媒方向的设计，我们几乎所有的设计都难以完成落地性，我们只能把设计停留在原型阶段，作为ui/ux设计师，却没有办法涉足那些真正交互的部分。
