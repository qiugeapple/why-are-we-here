# why-are-we-here
Ihde 的技术媒介理论提出：技术从来不是中立工具，而是会反过来塑造人的认知、限制或拓展人的想象力与创作边界。在我完整的本科学习周期中，我亲身见证了 AI 技术从辅助工具逐渐演变为主导设计流程的底层媒介，也深刻体会到“媒介认知缺失”对设计师创作能力的限制。短短三年间，设计学习的工作方式发生了颠覆性变化：大一阶段，所有论文、调研、视觉作业都需要依靠纯人力逐字撰写、手动搜集资料、从零手绘构思；到大二，AI 已经成为主流的信息检索与整理工具，大幅降低了资料搜集的机械成本；进入大三，AI 进一步渗透创意前端，成为我们头脑风暴、快速生成草图、发散视觉方案的核心辅助工具。AI 的迭代速度，让设计师的工作重心迅速从“执行产出”转向“判断、筛选与迭代”。
在这个过程中我清晰地感受到 AI 的巨大优势：它能瞬间将我脑海中模糊、碎片化、不成体系的感性想法，快速落地为可视化的清晰方案，极大缩短了从创意到初稿的距离。但真正的问题，也在这一过程中彻底暴露。在毕业设计阶段，我亲眼见证身边同学的真实困境：即便依靠 AI 可以快速生成整套设计内容，整体创作过程依然极度痛苦。以老人八段锦科普设计的同类毕设项目为例，同学可以轻松让 AI 产出大量视觉草图、版式方案与宣传内容，但始终无法解决核心问题：如何严格甄别AI生成内容是否贴合老年人八段锦科普的核心知识、是否准确传递养生健身、简易易学的科普主旨，如何筛选适配老年受众认知、视觉习惯的设计内容，锚定项目公益科普的核心方向，同时迭代修正AI内容失真、信息偏差、风格同质化的问题。AI可以无限生成视觉样式和内容素材，但它无法替设计师做决策。这让我意识到，AI 时代设计师的立身之本，早已不再是绘图、排版、建模等执行能力，而是内容定义、审美取舍、逻辑把控、方向决策的顶层能力。
更关键的是，工具与媒介会深刻反向塑造设计师的想象力，这也是我在视觉传达专业学习中最直观的体会。长期依赖传统纸媒、平面视觉工具，让我的创作思维被牢牢局限在二维平面体系内。我们的创意、构图、叙事方式几乎全部建立在静态平面逻辑之上，创作想象高度固化。也正因我和大多数同学都不了解代码、交互、动态媒介的底层逻辑，我们的设计永远止步于视觉原型阶段。作为视觉传达与 UI/UX 方向学生，我们可以完成界面外观、视觉版式、动态海报，却完全无法触及真正可落地、可运行的核心部分。我们只能想象“看起来怎么样”，却无法想象“实际运行起来是什么样”。
这正是不懂媒介所要付出的代价：你只能创作你能理解的媒介形态。设计的本质从来不是单纯的视觉美化，而是情感与价值的表达，是针对性解决实际问题的创造性行为。但我深刻意识到，倘若没有对应的技术语言作为转译载体，我们的创意表达便会受限，根本无法进一步落地设计、定义设计的核心价值与形态。这也是当下AI时代，设计师牢牢把握设计主权的关键所在。AI与代码归根结底都只是辅助设计的工具，工具本身不具备价值与意义，真正赋予工具内核、定义工具用途的始终是人。设计师拥有绝对的主导权，能够自主决定工具的应用场景、创作方向与价值内核，让技术服务于设计思维，而非被技术裹挟限制。AI可以高效完成平面视觉优化、素材生成等基础执行工作，却无法填补设计师缺失的技术认知、拓展空白的技术想象力。在AI全面替代基础执行工作的当下，设计师的核心差距，早已不在于绘图、排版等基础执行能力的优劣，而在于是否深谙媒介逻辑、能否突破传统设计边界、自主定义多元、先进、可落地的设计形态。因此，系统学习代码相关课程知识极具必要性，这不仅是补齐技术短板、打破传统纸媒带来的创作思维桎梏，更是为我的设计思维搭建完整的转译通道，拓宽创作想象边界，真正守住设计师的创作主导权与定义权，让我能够以技术为支撑、以思维为核心，主动驾驭工具、赋能设计，完成更具深度、落地性与创新性的设计创作。
